I'm a developer based in **Eldoret, Kenya**, building web apps that solve everyday problems for people in Kenya.

### 🚀 Currently building: Applyra

Applyra helps Kenyan university and college students apply for internships, industrial attachments and entry-level jobs without starting from scratch every time:

- CVs and cover letters tailored to each job advert, written only from the student's real profile — nothing invented
- Pay with M-PESA, then download in PDF or Word
- An application tracker with deadline and follow-up reminders

### 🛠️ Tools I work with
